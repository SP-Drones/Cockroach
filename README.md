**Cockroach** is an easily accessable FPV frame designed by **[Southern Performance Drones](https://www.spdrones.co.nz/)**.

Created to provide a cheaper entry point into sub 5" FPV, the Cockroach is a cost effective way to fly more ways in more places.

This repository contains printable accessories and documentation.

> The complete Cockroach frame kit and prints can be purchased from the Southern Performance Drones store.

## Specifications & Features

### Standard Configuration

| Component | Specification |
|----------|---------------|
| Weight | From **idk** |
| Arm Thickness | **3.5 mm** |
| Main Plate Thickness | **2.5 mm** |
| Mid Plate Thickness | **2.5 mm** |
| Top Plate Thickness | **2 mm** |
| Camera Plate Thickness | **2.5 mm** |
| Electronics Mounting | 20×20 mm / 25.5x25.5 mm |
| VTX Mounting | 20×20 mm / 25.5×25.5 mm |
| Camera Compatibility | HDZero Nano / Analog Nano / DJI / WS |
| Motor Mounting | 16×16 mm |

### Features

* Lightweight design
* Flexible electronics mounting
* Easy individual arm replacement
* Comfortable building experience 
* Compatible with standard 3.5-inch motors

## Repository Contents

### 3D Printable Parts

This repository contains printable accessories including:

* Camera mounts
* Antenna mounts
* Additional accessories

All printable parts are provided as STL and STEP files.

#### Need Something Else?

If the included mounts don't suit your build, feel free to open an Issue or contact Southern Performance Drones.

Additional camera mounts, camera angles, antenna mounts, and other printable accessories can be designed and added to the repository.

#### Included Camera Mounts

The repository currently includes camera plates for:

* Nano Cameras
* DJI Vista/O3/O4
* Walksnail
